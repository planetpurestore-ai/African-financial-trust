Current controls and limits

Security & Data Protection

AFT is a controlled demonstration and pilot platform. Security controls are being developed for responsible testing; independent certification, penetration testing, and all required regulatory or vendor approvals are not yet complete.

Controls currently implemented

The Trust Engine includes role-based access control, tenant isolation, MFA for administrator access, secure password hashing, encrypted secrets, encrypted session and API-key handling, CSRF protection, audit logging, hash-chained audit records, input validation, and controlled access to evidence and reports.

Operational limitations

No public page should be read as a claim of a completed certification or an approved production financial service. Backup and restore exercises, independent security testing, formal incident-response procedures, vendor reviews, retention schedules, and Rwanda data-protection registration or documentation remain launch work unless separately confirmed in writing.

Responsible disclosure

Do not send live customer data through a public demonstration. Report suspected security or privacy issues to hello@africanfinancialtrust.com with enough detail to reproduce the issue. Please do not include passwords, recovery codes, or unnecessary personal data.
